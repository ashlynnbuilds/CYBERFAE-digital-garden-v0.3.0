# CYBERFAE 🌱🧚‍♀️

**A digital garden for growing your intentions.**

CYBERFAE is a whimsical offline desktop productivity app where completing real-world tasks helps your digital garden flourish.

Featuring interactive fairy and fox companions, illustrated growing plants, and a cozy solarpunk-inspired greenhouse.

**Current release:** v0.3.0 Beta  
**Platform:** Windows 64-bit  
**Status:** Free beta

*Small actions grow beautiful worlds.*
